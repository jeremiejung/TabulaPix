Glissez pour ranger · Alt + ↑/↓ · Échap

Glissez une agence par sa poignée, entre deux agences ou sur un dossier.

    Ajouter une agence

    Faites une recherche sur le site de l'agence, puis collez ici l'adresse de la page de résultats et les mots-clés que vous avez tapés.

    Vos mots-clés y sont remplacés par {q}.

    TabulaPix ouvrira cette page, tapera les mots-clés dans le champ de recherche du site et cliquera sur son bouton. Montrez-lui où ils se trouvent :

    • Champ de recherche
    • Bouton de recherche

    Chrome vous demandera l'autorisation pour ce site.

    Détails techniques

    Pour les sites qui « emballent » la recherche dans l'adresse : {payload} dans l'adresse, le texte modèle contenant {q} ci-dessous, et les étapes d'encodage (uri, hex, gzip, base64) dans l'ordre. {q:slug} écrit les mots avec des tirets (estonie-frontière).
